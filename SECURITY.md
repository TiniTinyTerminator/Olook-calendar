# Security

Olook Calendar shows appointments from calendars other people publish, so
their text is only ever shown as plain text, reminders escape it, and the
widget reads everything through Olook, which holds the credentials; the widget
itself stores none.

## Reporting a vulnerability

Please report it privately: open the repository's **Security** tab and choose
**Report a vulnerability**. Include what you did, what happened, and the
version (`omarchy plugin list` shows it).

Please do not open a public issue for a vulnerability before it is fixed.

## Supported versions

Only the latest release gets fixes.
`omarchy plugin update ttt.olook-calendar` brings an installed copy up to date.
